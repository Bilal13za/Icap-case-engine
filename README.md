# ICAP Business Case Analysis and Decision Engine

An offline-first study app for ICAP CA students: case analysis practice for
**CAF-7 Business Insights and Analysis** and **CFAP-4 Strategic Business Finance**
(plus their verified 2021 predecessors, CAF-6 Managerial and Financial Analysis and
CFAP-4 Business Finance Decisions).

Deterministic and fully offline — rule-based problem recognition, a framework library,
a Decimal-safe calculation workbench, a decision comparator, a recommendation builder,
exam practice with a mistake log, and CSV/Excel export of workings. No AI, no accounts,
no network calls.

## Install

### Windows (recommended): double-click

1. Extract the ZIP anywhere (e.g. your Documents folder).
2. Double-click **`run_windows.bat`**.
3. First run only: it installs Python 3.12 via `winget` if missing, creates a virtual
   environment, installs dependencies, and builds the database. Needs internet **once**
   for this setup.
4. The app opens in your browser at http://localhost:8504. Your work is saved in
   `%LOCALAPPDATA%\ICAP Case Engine\case_engine.db`.

To stop the app, close the "ICAP Case Engine Server" window.

### Manual (any OS with Python 3.10+)

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python seed.py        # builds the database (idempotent; never wipes student work)
.venv/bin/python -m streamlit run app.py
```

## Offline operation

After the first-time setup, the app runs with no internet connection: the rule engine,
framework selection, calculations, and the SQLite database (with FTS5 search) are all
local. The automated test suite asserts that the engine, calculation, and database
layers contain no network imports or calls.

## Study Aids

The **Study Aids** screen (sidebar) adds four revision tools, all generated
deterministically from the app's own content — nothing is hand-invented and
everything works offline:

- **Flashcards** (210 cards) — pick a deck by paper → framework → card type,
  flip cards, and mark each **Know / Unsure**. Progress is saved per card in
  the database and survives re-seeding and backups. Every card shows its
  verification badge and inherits its source row's verification status.
- **Mind Maps** (27 maps) — one collapsible map per verified framework plus
  key supplementary frameworks with procedure steps. Rendered as offline HTML
  (`<details>`/`<summary>`, no JavaScript, no CDN).
- **Formula Sheets** — all 44 formulas grouped into 9 quick-sheets by
  decision area (investment appraisal, cost of capital & valuation, time
  value of money, breakeven & CVP, working capital & liquidity, ratios,
  relevant costing, variances, growth & trends), each with inputs, assumptions,
  limitations, and verification/validation badges.
- **Checklists** — the 11-point recommendation checklist (the app's own
  recommendation-template sections) and the 9-point exam answer-quality
  checklist, both interactive with progress bars.

Card and map content is generated by `tools/gen_study_aids.py` from
`data/frameworks.json`, `data/formulas.json`, `data/rules.json`, and
`data/calculation_examples.json`; re-running it reproduces
`data/flashcards.json` and `data/mindmaps.json` byte-for-byte.

## Backup and restore

Your attempts, mistake log, and flashcard progress live in the database file:

- Windows: `%LOCALAPPDATA%\ICAP Case Engine\case_engine.db`
- macOS/Linux: `~/.icap-case-engine/case_engine.db`

**Backup:** close the app, copy `case_engine.db` somewhere safe.
**Restore:** close the app, copy the backup back over `case_engine.db`.
Re-running `seed.py` never touches your attempts, mistake log, or flashcard
progress (verified by tests).

## Verification-status legend

Every content row carries a label — also shown in the UI:

| Label | Meaning |
|---|---|
| `verified_official` | Transcribed from an official ICAP source (Directive 1.01 Rev 2024 / official FAQ) |
| `provisional_predecessor` | 2025-paper topic mapped from its verified 2021 predecessor; detailed 2025 syllabus still pending official publication |
| `supplementary` | Standard business framework included for completeness; examinability not verified |
| `unverified` | Secondary-source claim, not officially confirmed (e.g. "CAPM/budgeting removed from CAF-7") |

All practice questions are original (`source_verified = 0`) — none are, or claim to be,
ICAP past papers. See `docs/VERIFICATION.md` for the full report.
